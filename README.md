# Rust TUI Audio Player (`v0.1.0-mvp`)

Консольный офлайн-аудиоплеер с терминальным интерфейсом (TUI), разработанный с использованием **AI-first подхода** в **Claude Code CLI** (кастомный `CLAUDE.md` + ролевые субагенты `@coder` и `@pentester`).

## Основные возможности (MVP)
- Сканирование локальной директории с аудиофайлами и навигация по списку треков в терминале.
- Воспроизведение, управление статусом трека и регулировка громкости в реальном времени.
- Базовая защита от некорректных входных данных и повреждённых файлов.

## Стек
- **Язык:** Rust
- **TUI / Audio:** `ratatui`, `crossterm`, `rodio` (см. `Cargo.toml`)
- **AI-воркфлоу:** Claude Code CLI, мультиагентная разработка и адверсариальное ревью

## Инженерные практики и безопасность
Проект прошёл внутренний аудит субагентом `@pentester` и покрыт тестами на граничные сценарии:
- **Санитизация вывода:** фильтрация управляющих ANSI-последовательностей в именах файлов для защиты от terminal injection.
- **Защита файловой системы:** проверка и блокировка выхода за пределы рабочей директории через символические ссылки (symlink traversal).
- **Устойчивость рантайма:** обработка ошибок декодирования без паник (`unwrap`) в основном цикле UI.

## Структура AI-воркфлоу в репозитории
- `CLAUDE.md` — системные правила разработки, инварианты безопасности и стандарты коммитов.
- `.claude/agents/` — конфигурации ролевых субагентов для разделения реализации и критического ревью.

## Запуск и тестирование
    # Сборка и запуск (с указанием пути к директории с музыкой)
    cargo run --release -- /path/to/music

    # Запуск тестов
    cargo test
